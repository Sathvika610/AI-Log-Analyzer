## Brand & Style
* **Core Archetype:** High-Contrast Dark-Mode Developer Minimalism.
* **Vibe:** Precise, technical, focused, and immersive. Designed specifically for deep coding sessions, incident triage, and fast-paced debugging environments.
* **Key Principles:**
  * **High-Signal Hierarchy:** Using precise chromatic accents against dark, layered charcoal surfaces to direct focus immediately to errors, stack traces, and actionable fixes.
  * **Zero Visual Noise:** Clean separation of panels, hair-thin boundaries, and structured typography that handles dense data without feeling cluttered.
  * **Tactile Precision:** Crisp geometry, subtle glows for active states, and instant visual feedback for developer actions like copying code blocks or filtering logs.

## Colors
* **Canvas Primary (`#0B0F19`):** Deep, immersive dark base that reduces eye strain during prolonged debugging sessions.
* **Surface (`#111827`):** Elevated structural background used for primary layout zones and sidebars.
* **Card & Panel (`#1E293B`):** Distinct container tone for grouping log snippets, AI insights, and actionable widgets.
* **Borders (`#334155`):** Crisp structural dividing lines that delineate panels and controls without relying on heavy drop shadows.
* **Text Primary (`#F8FAFC`):** High-contrast off-white for headers, code, and primary telemetry.
* **Text Secondary (`#94A3B8`):** Muted slate for metadata, timestamps, and inactive navigational items.
* **Accent Electric Indigo (`#6366F1`):** Purposeful interactive focus color for primary buttons, active tabs, and key triggers.
* **Semantic Status:** 
  * **Critical Red (`#EF4444`):** Fatal errors and crash states.
  * **Warning Amber (`#F59E0B`):** Warnings and throttling alerts.
  * **Success Emerald (`#10B981`):** Resolved statuses and successful build indicators.

## Typography
* **Inter** provides pristine legibility across all UI chrome, dashboards, and conversational panels.
* **JetBrains Mono** is strictly reserved for log outputs, stack traces, terminal commands, and inline code snippets to maintain alignment and readability when scanning raw telemetry.
* **Scale Discipline:** Large display sizes scale down gracefully on mobile viewports to prevent overflow while retaining strict modular hierarchy.

## Layout & Spacing
* **Layout Model:** Fluid multi-column workspace layout optimized for split-pane developer interfaces (AI Summary, Log Viewer, and Assistant Chat).
* **Grid Structure:** Strict 8px baseline grid system governing all vertical rhythms, padding increments, and component alignments.
* **Responsiveness:** Adapts from a single-column stacked view on mobile devices to a high-density 3-column layout on desktop viewports without sacrificing panel legibility.

## Elevation & Depth
* **Surface Layering:** Uses tonal shifts (`#0B0F19` canvas, `#111827` surface, `#1E293B` cards) rather than heavy drop shadows to create spatial separation.
* **Low-Contrast Outlines:** Relies on crisp, hairline borders (`#334155`) to demarcate functional panels, interactive zones, and input containers.
* **Subtle Glows:** Minimalist ambient glows using the Electric Indigo accent (`#6366F1`) or semantic colors (`#EF4444`) are reserved strictly for active states, critical errors, and modal focus.

## Shapes
* **Corner Radius:** Soft, utilitarian roundedness (`0.25rem` to `0.5rem` / `8px` to `12px`) for cards, inputs, and code blocks to maintain an engineered, modern developer tool aesthetic without excessive pill-shapes.
* **Interactive Elements:** Buttons and badges use concise rounding (`6px`–`8px`) to fit cleanly within dense toolbar layouts and tables.

## Components
* **Buttons:** Solid Electric Indigo (`#6366F1`) for primary triggers with instant hover brightening; ghost buttons use subtle surface fills (`#1E293B`) with light borders.
* **Input Fields:** Dark surface inputs (`#111827`) featuring `1px solid #334155` borders and a `2px` Electric Indigo focus ring.
* **Log Viewer:** Monospace container utilizing alternating row tints and left-edge severity indicators (`#EF4444`, `#F59E0B`, `#10B981`) for instant visual scanning.
* **Cards & Panels:** Structured containers (`#1E293B`) with clear header regions, metadata chips, and built-in copy-to-clipboard functionality for code patches.
* **Badging & Status Pills:** Compact inline tags using semantic status colors with low-opacity background washes for quick severity identification (`FATAL`, `ERROR`, `WARN`, `INFO`).
